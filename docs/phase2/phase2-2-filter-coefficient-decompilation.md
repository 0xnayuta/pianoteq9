## 二、阻抗与衰减关系的候选模型（非逆向结论）

以下内容为【候选模型】：它们由公开声学常识与历史静态记录**外推**而来，本轮无任何证据表明 Pianoteq 内部实现了这些方程。参数取值范围在本仓库（含随附官方手册）中**找不到可核原始来源**：Phase 2-2 原文写 `Impedance` 为 $[0.10, 20.00]$、`Cutoff` 为 $[0.3, 3.0]\ \text{kHz}$、`Slope` 为 $[0.2, 10.0]$；同一历史修订的参数字典又写 $0.20 \sim 3.00$ 与 $500\ \text{Hz} \sim 10\ \text{kHz}$，两份记录互相冲突且都无出处（该字典条目已在本次复核中删去范围）。因此本报告不保留任何滑块数值边界或默认值作为结论。

### 1. 延音时长与阻抗的单调关系（官方语义）与线性缩放（候选）
【官方语义】随附 9.1.2 英文手册：阻抗越大，声音越长但越弱；越小则越响但越短；机械阻抗定义为力/速度，且“阻抗随频率变化”。这是公开可核的定性方向，属本轮准入语义。
【候选模型】原文据此写出 $\gamma_0 \propto 1/Z_{sb}$ 与线性缩放

$$\tau_0(k) = \tau_{\text{nominal}}(k) \cdot \left(\frac{Z_{sb}}{Z_0}\right),\qquad Z_0 = 1.0$$

其可成立的前提是若干未经验证的理想化假设：单一模态、理想无耗弦、纯阻性端接、高阻抗极限（否则反射系数 $|r|$ 与 $Z$ 不是简单反比）、且滑块标量 $\leftrightarrow$ 物理阻抗的映射已知。单位与假设： $\tau_0$ 与 $\tau_{\text{nominal}}$ 为时间常数（s）， $Z_{sb}$、 $Z_0$ 为无量纲滑块标量（非物理 Ω 或 N·s/m，除非另证映射）。官方只承诺单调方向，**未**承诺线性、正比常数或与基频无关。原文“轻薄薄膜/强刚性边界反射”“歌唱性延音”等叙述为【候选模型】的定性想象，不作为结论；“班卓琴效应”等类比同样不是测量结果。
【经典理论】在无损弦-阻性端接的理想模型中可证明衰减率在 $Z \gg Z_{\text{string}}$ 时近似 $\propto 1/Z$；这属于理论边界条件，不能被引用为该软件的实现证据。

### 2. 截止频率与斜率的频域损耗（候选形式）
【官方语义】截止频率越高，能保持较长时间的高次分音越多；截止以上分音的衰减快于低频。手册对 `Impedance Slope` 的方向描述**自身存在矛盾**：8.1.1 节表格称“该因子越大，高次分音衰减越快”，教程 3 又称“把该滑块下调会增大阻抗斜率，从而缩短截止以上分音时长”。两处对滑块增大方向的含义不一致，且手册把该斜率称作 “Q factor”（Q 不是斜率，术语本身也不严谨）。因此本条只准入“截止以上衰减更快”与“截止频率越高、长时值高次分音越多”两点，滑块单调方向不予准入。
【候选模型】原文给出幂律损耗因子与双阶段时间常数

$$D(f) = 1.0 + \left(\frac{f}{f_c}\right)^{S},\qquad
\tau(f) = \frac{\tau_{\text{nominal}}(k) \cdot \left(\dfrac{Z_{sb}}{Z_0}\right)}{1.0 + \left(\dfrac{f}{f_c}\right)^{S}}$$

单位与假设： $f$、 $f_c$ 为 Hz， $S$ 无量纲（原文未说明是否限整数）；该式仅在 $f \ge 0$、 $f_c > 0$ 时有定义，且要求 $D(f)$ 恒为有限值。函数形式（ $1+(\cdot)^S$ 而非其他单调族）、与 `Impedance` 相乘的可分离结构、以及“低频分音完全受控于阻抗”的解释，均无证据支持。原文“完美再现……木质纤维吸收”的判断句撤回为候选描述。

## 三、离散损耗滤波器的候选形式（非逆向结论）

【候选模型】原文称“Pianoteq 采用一阶或二阶双线性变换损耗滤波器”，并给出形式与系数。该归属无证据：本节所有公式均为**通用数字滤波器教科书内容**，与上面三处静态记录之间没有任何已验证的指令级联系；也没有证据表明采样率为 48 kHz、使用一阶或二阶结构、或采用该预畸变路径。保留仅为候选参考。

$$\text{一阶候选：}\quad H_{\text{loss}}(z) = \frac{b_0 + b_1 z^{-1}}{1 - a_1 z^{-1}}$$

【经典理论】双线性变换的标准步骤（ $f_s = 1/\Delta t$， $\omega_c = 2\pi f_c$）：
1. 预畸变（frequency warping）： $\omega_d = \dfrac{2}{\Delta t}\tan\left(\dfrac{\omega_c \Delta t}{2}\right)$；
2. 定义 $g = \tan\left(\dfrac{\omega_c \Delta t}{2}\right)$，取 $k_z = 1/Z_{sb}$；
3. 得到 $a_1 = \dfrac{1 - g k_z}{1 + g k_z}$， $b_0 = \dfrac{g k_z}{1 + g k_z}$， $b_1 = b_0$。

【候选模型】原文称该一阶极点滤波器“在每个往返循环上施加复数幅值衰减，无缝复现音板机械阻抗响应”。即便数学形式成立，也需额外未验证条件： $Z_{sb}$ 已被正确映射为物理阻抗、滤波严格位于波导回路内、且 $Z_{sb}$ 缩放与截止频率参数彼此独立。这些条件在静态记录中均无证据；实际参数→系数路径未经数据流反汇编确认。原文 $f_s = 48000\ \text{Hz}$ 的假设同样只是当时的测试环境猜测，不是目标二进制或官方文档给出的内部采样率契约。
