## 2. 准入规则（三类）

| 类别 | 键域 | 规则 |
|---|---|---|
| **直接准入（anchor）** | 21/24/36/43/48/60/69/72/84（9 键） | 取该键全部通过族的中位数。单力度锚点（21/24 仅 v41；84 仅 v70/v98）准入并标注置信度等级 |
| **插值（interp）** | 21–84 之间其余键（含 44，共 57 键） | 相邻锚点之间在 log(B) 空间线性插值 |
| **保持模型常量（model）** | 85–108（24 键） | 无 C6 以上实测证据：从 C6 锚点向保留的模型上界锚点 `{96: 4.0e-2, 108: 8.5e-2}` 插值；96/108 与现行一致 |
| **下界（clamp）** | 0–20 | clamp 到 A0 锚点值（与现行 `getNoteParams` 的 clamp 语义一致） |

**候选表相对现行的关键差异**：低音区（21–48）现行偏高 **2.3–4.4 倍**；中音（57–72）偏高 3.5–16%；C6 偏高 58%；85–95 随 C6 锚点自动下移（比值 ~0.66–0.80）；96–108 不变。

## 4. 对照指标（冻结）

以下全部取自预登记 `acceptance_metrics` 与 `physical_admission`，**本方案确认后冻结，校准结果不得反向修改指标**：

| 指标 | 判据 | 应用方式 |
|---|---|---|
| `A4_audio` | 同一识别线在 400/440/480 Hz 下 ≤0.07 Hz（ageing 0；mono 混合峰不得替代线识别） | 校准后 A4 渲染对照 |
| `intervals` | 预选 4:2（A4 下方）与 2:1（A4 上方）匹配误差 ≤1 cent（插值带外；中心插值例外须记录） | 校准后渲染对照 |
| `pitch_order` | 44.1/48 kHz 上相邻键严格递增；8 kHz 安全/退化单列 | 全键扫描 |
| `Nyquist` | 有限有界长音频；无超安全带的主动振荡器；非线性 alias 残差单独观察 | 全键扫描 |
| `block_rate_consistency` | 同线 44.1/48 kHz ≤0.1 cent；归一化谱与 RMS 偏移 ≤0.5 dB | 双率对照 |
| `B_stability` | 窗口/重复相对 B 散布 ≤10% | 锚点已满足（≤0.87%），校准后复算 |

## 5. 实施建议（供确认后的代码任务）

1. **改动点**：`Piano88KeyTable.h` 的 `computePianoNoteParams` 第 4 段——bass/tenor 两段替换为锚点插值（4+锚点分段或 88 键常量表均可，推荐保持对数分段插值形式，段点＝锚点）。
2. **`isBassBridge` 字段保留**：当前唯一消费者是 B 段选择（代码核查确认）；移除 B 分段后该字段仅作描述性保留，不参与 B 计算。
3. **拉伸自动联动**：`pianoTuningDetail::makeStretchRatios` 经 `octaveStretchCents` 消费 B——B 改动会同时改变逐键拉伸曲线（"同轮复核逐键拉伸"的实质），实施后须重跑调谐/分音/邻键相关回归。
4. **一次性切换**：无兼容分支、无旧表别名、无迁移链（YAGNI）；测试中无对 B 值的硬编码断言（grep 确认），但频谱/调谐测试可能间接受影响，须全量回归。
5. **本轮不改代码**；实施范围与验收计划按第 6 节。

## 6. 验收计划（实施完成后）

1. Windows Debug 构建 + 默认完整 CTest；
2. 离线渲染全键扫描：回收锚点键的 f1/B、验证插值连续性（44/45–47 区段）、邻键顺序、Nyquist 安全；
3. A4 锚点（400/440/480 Hz）与音程（4:2、2:1）指标；
4. 双率一致性（44.1/48 kHz）；
5. **封闭验证集**：仅在 1–4 全部通过后一次性打开（失败即消耗，遵循预登记 `holdout_policy`；验证数据不得用于调参）。
