## 1. 修订内容（冻结）

`pilot/tools/pilot-partial-analysis.py` 的 nearest 精化轮（`analyze_unit` 内，用于修正“窗内更强非族峰遮蔽真分音”的情形）增加**候选强度守卫**：

1. 对每个分音号，在容差窗（`STAGE_B_TOL = 0.007`，不变）内收集候选峰；
2. 设窗内候选的最大相对功率为 `rel_max`，仅接受 `rel ≥ rel_max × 10^(−G/10)` 的候选，**G = 20 dB**；
3. 在通过守卫的候选中取**距模型预测最近**者为该分音的观测峰；
4. 通过守卫的候选为空时，退回窗内**最强**候选（等价于 strongest 行为）；
5. 精化轮的其他机制不变：分音补全能力保留；采用条件（精化后拟合残差 `refined_max ≤ current_max`）不变。
6. 实现登记：常量 `REFINEMENT_GUARD_DB = 20.0`；CLI `--refinement-guard-db`（默认 20；`off` 复现 legacy 行为，供审计与消融）。含本修订的工具版本 SHA-256：`80fa2c9f73c9c07ffdeeee8c0e345fc29986449c139c201b9fb0833c6e9442ff`。

## 2. 理由（防“放宽”审查）

1. **物理依据**：同一分音在 ±0.7% 容差窗内的候选峰，相对强度差超过 20 dB 时，弱峰在物理上不可能与该分音对应——实测伪影案例中伪峰比真峰低 **59 dB**（−65 dB vs −6.5 dB），且其局部 SNR 仅 24 dB。
2. **不改正常行为**：真实候选间（双弦分裂双峰、devpiano 三峰）的强度差 ≤1 dB（n26 案例 0.9 dB、n63-dev 案例 0.2 dB），守卫不干预；interp-training 全部 18 族在守卫下与 legacy 结果逐位一致（0 族变化，见 §4.3）。
3. **不引入新语义**：观测值仍是真实谱峰频率，不是加权质心或插值量；不改变“哪些分音进入集合”的可比较性规则（amendment-3 继续机械排除设计区）。
4. **G 选择有安全余量**：有效区间为 (1, 59) dB（下界 = 真峰间最大观测差、上界 = 伪影案例强度差）；20 dB 为对数中位，两侧各留 ≥19 dB 余量。敏感性见 §4.4。
5. **判据不放宽**：误差定义、比较集、基准、阈值、独立预测口径全部保持。

## 4. 验证标准（登记后执行）

1. **validation-interp 诊断对照**（判据 = amendment-3/4）：guarded 模式通过数 **48/48**；legacy 复现 46/48；两口径并列记录。
2. **sealed 诊断对照**（判据 = f(n)/f(1)、RMS ≤1 / max ≤3）：guarded 模式结果与 legacy **一致**（期望 12/28）；若不一致，逐单元登记差异原因（不得据此改写历史判决）。
3. **interp-training 族一致性**：guarded 与 legacy 的族级 effective_B / f1 / 通过状态逐位一致（期望 0 差异）。
4. **守卫敏感性**（G ∈ {10, 20, 30}，记录性）：validation-interp 与 sealed 在三个 G 下的通过数与关键分音差异登记；G=20 的最终选择需满足 §1/§2 且与 G=10/30 在“伪影拦截”与“正常行为保持”上不冲突。
5. **锚点复算**（训练集，非判决集）：按 `calibration/tools/anchor-admission-analysis.py` 的注册政策（n26 = v41 双率族中位数；52/57 = 全部通过族中位数）复算 26/52/57；与已实施值对比并按用户决策处理。
6. **评估产物并列要求**：使用本修订的评估必须同时记录 legacy（`--refinement-guard-db off`）与 guarded 的关键统计（通过数、逐单元 RMS/max、异常分音清单），仅作敏感性记录，不参与判据。

## 5. 生效范围与限制

- 生效：其后登记的新验证数据的判据执行；训练集的参数复算；后代工具的默认行为。
- 不生效：已归档判决、已实施生产参数（须独立决策）、已冻结的历史预登记与其评估器散列。
- 限制：本修订只解决“强度悬殊伪峰抢占”一类缺陷；双弦双峰间的选择歧义（n26 = 6.868533e-5 vs 6.846790e-5 的策略敏感度）**不由本修订处理**，登记为下一代协议的分音语义议题（若需要，另行登记 amendment）。
