
## 4. 分批方案

### 4.0 批 0：前置能力验证（1 个冷启动；数据不入 Pilot 集）

- 目标：关闭 R1–R4——验证 24-bit、48000 Hz、连续多导出（2–3 个）、单导出耗时基准。
- 内容：用 note 60 / vel 70 连续导出 ≤3 个测试文件，**全部标记 diagnostic-only**，不计入 36 个数据集。
- 产出：导出对话框完整操作序列记录；WAV 头证据（bit_depth / sample_rate 解析）；单导出耗时表。
- 退出条件：R1–R4 全部确认 → 进入批 1；任一不满足 → **暂停并请求决策（D4）**。

### 4.1 正式单元（12 个会话）

- 单元定义 = (note, rate, repeat)：3 × 2 × 2 = **12 个单元**；每单元 3 个导出（vel 41/70/98）。
- **rep0 与 rep1 安排在不同冷启动**（跨会话重复；证据强度与 092853 的确定性证明同级）。
- 建议顺序：60/44.1k/rep0（与已验收流程最接近）→ 60/48k/rep0 → 48/44.1k/rep0 → … ；rep1 单元在同 note 的 rep0 完成后再展开。
- 会话预算（软约束；硬边界 900 s / 1200 s）：
  - 准备（启动 + 四步 GUI + FXP 加载 + 读回）约 180–240 s（092853 实测口径）；
  - 每导出约 40–90 s（批 0 后修正）；
  - 退出（quit + 凭据）约 150–240 s；
  - **每会话导出数上限 3**；若批 0 实测单导出 > 90 s，降为 2/会话（单元数相应上调并另行确认）。
- 单元完成标准：3 导出 + pre/post 参数零漂移 + exit 0 + WAV 头与协议一致 + 逐文件散列登记。

## 6. 决策项（待用户确认）

- **D1 分批粒度**：12 单元 × 3 导出（推荐） vs 6 会话 × 6 导出（时间紧、超界风险） vs 18 会话 × 2 导出（最稳但会话数翻倍）。
- **D2 重复分布**：跨会话（推荐，与 092853 同级证据强度） vs 会话内（省一个单元但证据较弱）。
- **D3 授权方式**：批 0 独立授权 → 复核结果 → 再授权批 1–12（推荐） vs 一次性授权全部 13 个会话。
- **D4 24-bit 不可用预案**：暂停并请求决策（推荐） vs 降级 16-bit 记录偏差继续（需评估对分音分析的实质影响）。
