# Task 39-2 方法修订 3：验收分音集（可比较分音口径）

- 登记：2026-10-13。**先登记后执行**：本修订对其后登记的新验证数据生效；对已消耗 holdout 的分解仅作诊断记录（`closure-diagnosis-20261013-230813`）。
- 触发：缺口诊断的逐分音分解显示——n50（D3）的失败**完全来自拍频区**（n≤6 RMS 1.75；n≥7 RMS 0.57 全通过）；拍频区（devpiano `beatingPartials` 覆盖段）的分音位置由 devpiano 单侧同音弦微失谐设计（Phase 19-C 常量）决定，而参考（unison width = 0）未施加同类分化——两侧几何条件不同，该区分音位置不可比。
- 性质：**判据适用范围修订**（明确"独立分音"的可比较性条件）。判据数值不变（RMS ≤1 / max ≤3 cents）；不放宽、不改写任何既有判决。

## 1. 修订内容

跨生产者验证（参考 vs devpiano）的误差计算使用**可比较分音集**（comparable partial set）：

- 分音 n 进入判据集的条件：两侧该分音位置均由各自非谐性（B）决定，不受单侧同音弦分化设计的主动影响；
- 操作定义（机械规则，评估前冻结）：排除 devpiano 侧 `beatingPartials` 覆盖的分音号——当前实现即 n ≤ 6（MIDI < 72）、n ≤ 4（72 ≤ MIDI < 96）、无排除（≥ 96）；
- 被排除的设计区**单列为探测性指标**（`design_zone_rms` / `design_zone_max`），永久记录、不参与判据；
- 全部口径（含设计区）继续并列记录于产物（`all_rms` / `all_max`），任何审计可核对两口径差异；
- 归一化基准（`f(n)/f(m)`，m = 两侧共同可识别的最小分音号）与 amendment-1 定义不变。

## 2. 论证（防"放宽"审查）

1. 被排除分音的位置差异来源是**单侧设计自由度**：devpiano 对同音弦施加 0.0010–0.0020 比例的微失谐（独立于 B 的设计常量），参考为 width=0（无分化）。两者是三弦行为的设计选择差异，不是 Task 39-2 的校准对象（B 表）。
2. 既有登记一致：校准报告 §4 记载"devpiano 渲染的非拍频分音（n≥7）与表值吻合 ±0.01 cents；拍频区观测峰偏 −detune 侧（如 48 键 −3.0 cents）为 Phase 19-C 常量所致"。
3. 数值判据不放宽；排除集合由**分音号规则**机械确定（不逐数据挑选）；两口径永久并列。
4. 设计区差异登记为 **Phase 40（同音弦耦合深化）**的输入：若未来逼近参考的三弦行为，属特征工程，不是验收豁免。
